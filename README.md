# TavernGamesVisual — Визуальные тавернные игры для Skyrim SE 1.6.1170 (SKSE 2.2.6)

Полноценный графический мод на базе **SKSE C++ DLL + DirectX 11 + Dear ImGui + собственные текстуры и звуки**.
Никаких текстовых `MessageBox`, никакого `.esp` (ноль конфликтов и вылетов при загрузке), не требует Address Library.

## Что внутри
- **Визуальное лобби «Стол таверны»** — выбор игр по графическим карточкам с текстурами, выбор ставки (10–250 септимов) и сложности соперника (Новичок / Бывалый / Мастер).
- **6 полноценных графических мини-игр с управлением мышью:**
  1. **Дартс 301** — текстурированная мишень, покачивание прицела, шкала точности броска (зажать и отпустить ЛКМ), сектора x2/x3/Буллзай, ответные броски ИИ.
  2. **Шашки 8×8** — резная деревянная доска, текстурированные белые/чёрные фишки и дамки с короной, подсветка ходов и обязательных взятий, цепочки взятий, умный ИИ.
  3. **Покер на костях** — 5 резных костей с текстурным атласом на красном сукне, анимация броска, клик по костям для удержания, 2 переброса, все покерные комбинации.
  4. **Блэкджек (21)** — карты с узорной рубашкой, пергаментным лицом и векторными мастями, скрытая карта дилера, кнопки «Взять», «Хватит», «Удвоить».
  5. **Напёрстки (3 кубка)** — 3 резных кубка и золотой септим, плавное дуговое перемешивание с ускорением, выбор кликом.
  6. **Септим (Орёл/Решка)** + **Зал Славы** — анимированный подброс монеты, статистика, звания и кошелёк таверны.
- **13 готовых PNG-текстур** и **7 WAV-звуков**.

## Как получить готовый `.dll` за 1 минуту (без установки Visual Studio)
1. Создайте новый пустой репозиторий на GitHub и загрузите туда все файлы из этого архива (включая скрытую папку `.github/workflows/build.yml`).
2. Перейдите во вкладку **Actions** вашего репозитория — сборка **Build TavernGamesVisual** запустится автоматически (~45 секунд).
3. Откройте завершённую сборку и скачайте внизу артефакт **`TavernGamesVisual-SkyrimSE-1.6.1170`** — внутри уже готовый `.zip` с `Data/SKSE/Plugins/TavernGamesVisual.dll`, текстурами и звуками.

## Локальная сборка (если установлена Visual Studio 2022)
```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
```

## Установка в Skyrim SE 1.6.1170
1. Удалите старый `TavernGamesSE.esp` и его скрипты/текстуры, чтобы убрать вылеты.
2. Распакуйте собранный архив в папку с игрой (чтобы внутри `Data\SKSE\Plugins\` лежали `TavernGamesVisual.dll`, `TavernGamesVisual.ini` и папка `TavernGamesVisual\`), либо установите через Mod Organizer 2 / Vortex.
3. Запускайте игру через `skse64_loader.exe`.

## Управление в игре
- **`F8`** — открыть или закрыть стол тавернных игр в любой момент (клавишу можно поменять в `Data\SKSE\Plugins\TavernGamesVisual.ini`).
- **`Esc`** — быстро закрыть стол.
