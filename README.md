# TavernGamesVisual — визуальные тавернные игры для Skyrim SE/AE

Графический мод на базе **SKSE C++ DLL + DirectX 11 + Dear ImGui** с собственными текстурами и звуками. В этой версии добавлена Papyrus-функция для открытия лобби из диалога NPC.

## Что внутри

- **Визуальное лобби «Стол таверны»** — выбор игр по графическим карточкам с текстурами, выбор ставки (10–250 септимов) и сложности соперника (Новичок / Бывалый / Мастер).
- **6 графических мини-игр с управлением мышью:**
  1. **Дартс 301** — текстурированная мишень, покачивание прицела, шкала точности броска, сектора x2/x3/Буллзай и ответные броски ИИ.
  2. **Шашки 8×8** — деревянная доска, текстурированные фишки и дамки, подсветка ходов и обязательных взятий, цепочки взятий и ИИ.
  3. **Покер на костях** — пять костей, анимация броска, удержание костей, два переброса и покерные комбинации.
  4. **Блэкджек (21)** — карты, скрытая карта дилера, варианты «Взять», «Хватит», «Удвоить».
  5. **Напёрстки (3 кубка)** — три кубка и септим, анимированное перемешивание.
  6. **Септим (Орёл/Решка)** + **Зал Славы** — подбрасывание монеты, статистика, звания и кошелёк таверны.
- **13 PNG-текстур** и **7 WAV-звуков**.
- **Papyrus-вызов `TavernGamesNative.OpenGames()`** — отдельная точка входа для диалогов и других Papyrus-скриптов.

## Запуск

- **F8** — открыть или закрыть стол в любой момент (клавишу можно поменять в `Data/SKSE/Plugins/TavernGamesVisual.ini`).
- **Из диалога NPC** — в End-фрагменте Topic Info вызывается `TavernGamesNative.OpenGames()`. Пример готового фрагмента и инструкция по созданию диалога находятся в `Integration/`.

## Важное о диалоге

В исходном архиве TavernGamesSE не было ESP/ESL с записями NPC-диалога. Поэтому DLL теперь умеет открывать меню по команде Papyrus, но саму реплику NPC нужно добавить отдельным небольшим плагином в Creation Kit. В `Data/Scripts/Source/TavernGamesNative.psc` находится объявление native-функции; его нужно скомпилировать в `TavernGamesNative.pex`. Подробности — `Integration/SETUP_RU.md`.

## Требования

- Skyrim SE/AE **1.6.1170**.
- SKSE64 **2.2.6**.
- Address Library for SKSE Plugins (формат V5 для runtime 1.6.1170).
- Для запуска через NPC-диалог: `TavernGamesNative.pex` и созданный в Creation Kit `TavernGamesDialogue.esp`.

## Сборка

В проекте используется CommonLibSSE-NG для безопасной регистрации native Papyrus-функции. GitHub Actions скачивает CommonLibSSE-NG и зависимости через vcpkg, затем собирает DLL.

Локальная сборка (Visual Studio 2022, CMake 3.21+, vcpkg):

```powershell
# Сначала поместите CommonLibSSE-NG в extern/CommonLibSSE.
cmake -B build -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" `
  -DVCPKG_TARGET_TRIPLET=x64-windows-static `
  -DVCPKG_MANIFEST_MODE=ON
cmake --build build --config Release --parallel
```
